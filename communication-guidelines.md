# Communication guidelines (template)

This is the shipped template. It is a neutral starting point so the skill works
out of the box for anyone.

**To make it yours:** copy this file to `communication-guidelines.local.md` in the
same folder and edit it. The skill reads the `.local` version first and falls back
to this template. The `.local` file is git-ignored, so your personal voice never
gets published. Do not put your own private guidelines in this file.

Apply these to every drafted title, body, executive summary and callout.

## Writing rules (edit freely)

1. **Conclusion first.** Every slide title is an assertion (the so-what), not a
   label. State the answer before the evidence.
2. **One idea per title.** Quantify where you can.
3. **Plain, confident prose.** Write like an experienced colleague, not like a
   consultant pitch or a generic AI draft.
4. **Avoid filler and hype words** (e.g. leverage, robust, seamless, crucial,
   pivotal, showcase, "it's important to note", "in today's world").
5. **Vary sentence length.** Avoid a wall of short, curt lines.
6. **Real content, no lorem ipsum.** Use concrete, plausible figures and names.
7. **Close on an explicit ask.** One decision slide stating what you want approved.

## Language and spelling

- Default language: English. Change this line to match your audience.
- Pick one spelling convention (e.g. British/EU: optimisation, licence, realise)
  and keep it consistent.
